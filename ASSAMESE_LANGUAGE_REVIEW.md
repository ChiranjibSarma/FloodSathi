# Assamese language review

No Assamese emergency copy is claimed as field-approved. Any provisional copy carries `REQUIRES_NATIVE_ASSAMESE_REVIEW`.

Native review checklist: meaning matches English; calm and non-authoritative tone; Assam usage; readable on low-end phones; emergency disclaimer unambiguous; no medical/rescue advice; screen-reader pronunciation checked; field test with diverse speakers; reviewer/date/version recorded. Remove the marker only through an approved review change.
